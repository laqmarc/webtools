CSV a JSON

Detecta el separador, respecta les cometes i tipa els valors.

Converteix una taula en una llista d’objectes JSON, amb les capçaleres com a noms de camp. El separador es detecta sol mirant la primera línia, però el pots forçar si la detecció falla.

El lector segueix les regles de l’RFC 4180: respecta les cometes, les cometes dobles escapades a dins d’un valor i els salts de línia enmig d’un camp entre cometes.

Com es fa servir

  1. Enganxa el CSV o obre el fitxer.
  2. Comprova que el separador i la casella de capçaleres siguin correctes.
  3. Copia el JSON o baixa’l.

Preguntes freqüents

Què fa l’opció de convertir números i booleans?
Sense ella, tot surt com a text entre cometes. Amb ella, «42» passa a ser el número 42 i «true» el booleà. Els valors que semblen números però no ho són exactament, com un codi postal amb zero al davant, es deixen com a text.
El meu CSV no té capçaleres.
Desmarca la casella corresponent. Cada fila sortirà com una llista de valors en comptes d’un objecte amb noms de camp.
Què passa si dues columnes es diuen igual?
La segona guanya, perquè un objecte JSON no pot tenir dues claus iguals. Canvia el nom d’una de les columnes abans de convertir.
