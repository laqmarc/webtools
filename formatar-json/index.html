Formatar i validar JSON

Indenta, minifica o ordena claus, i assenyala l’error amb línia i columna.

Indenta, minifica o ordena les claus d’un JSON, i quan no és vàlid t’indica la línia, la columna i què hi esperava.

El motor del navegador ja no diu on falla, així que quan el JSON no passa la pàgina el torna a recórrer amb un analitzador propi que sí que ho pot dir: «sobra una coma abans de }», «s’esperava el nom d’una clau entre cometes dobles», i sempre amb la posició exacta.

Com es fa servir

  1. Enganxa el JSON, tan desordenat com calgui.
  2. Tria si el vols indentat, minificat o amb les claus ordenades.
  3. Copia el resultat.

Preguntes freqüents

Per a què serveix ordenar les claus?
Per comparar dos JSON que tenen el mateix contingut en diferent ordre. Un cop ordenats tots dos, un diff de text només mostra les diferències reals.
S’hi puja el fitxer enlloc?
No. Tot passa dins de la pestanya, cosa que importa quan el JSON que enganxes conté claus d’API o dades de clients.
Accepta JSON amb comentaris o comes finals?
No, i t’ho dirà amb la posició exacta. Això no és JSON estàndard, encara que alguns fitxers de configuració ho admetin.

Eines relacionades

JSON a CSVArray d’objectes a taula, aplanant els objectes imbricats. CSV a JSONDetecta el separador, respecta les cometes i tipa els valors. JSON a YAMLConversió directa mantenint l’ordre de les claus. YAML a JSONAccepta diversos documents en un mateix fitxer. Descodificar JWTCapçalera, càrrega útil i caducitat. La signatura no es verifica.

Res no puja a cap servidor. Tot el processament passa dins d’aquesta pestanya.
