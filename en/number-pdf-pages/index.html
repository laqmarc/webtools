Number the pages

Adds page numbers, in the format and position you choose.

Add page numbers to a PDF that has none, which is the usual situation after merging several documents or scanning a stack of sheets.

You choose the format — bare number, “1 / 10”, “Page 1 of 10” — the position, the size and which page starts the count, so the cover does not take number one.

How to use it

  1. Drop in the PDF.
  2. Choose the format and where it goes.
  3. If there is a cover, say how many pages to skip.

Frequently asked questions

How do I leave the cover unnumbered?
Put 1 in “skip the first”. Numbering starts on the second page, and the number shown is whatever you set in “start at”.
Does the number cover the content?
It can, if the document already has text low down. Raise the margin until it is clear; it is measured in points, and 28 is a shade under a centimetre.
Can it be undone?
Not from here, so keep the original. The number becomes part of the page content.
