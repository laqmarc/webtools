PNG to PDF

PNG screenshots and graphics into a single PDF, one per page.

Turn PNG screenshots, drawings and diagrams into a PDF with one image per page. Good for delivering a set of screenshots as a single document, or printing a series of plates.

Unlike JPEGs, PNGs are recompressed when embedded in the PDF, so the result usually weighs less than the sum of the originals.

How to use it

  1. Drag the images in the order you want them.
  2. Choose the page size, orientation and margin.
  3. Press “Combine” and download the PDF.

Frequently asked questions

Is transparency kept?
The PDF paints transparent areas white, which is what you will see when printing. If you need the alpha channel, keep the images as PNG.
The screenshot prints blurry — why?
Because a screen PNG has few pixels for the paper size. With the “Each image’s own” page size the PDF keeps the original resolution instead of stretching it to A4.
Can I add margins?
Yes, as long as you pick a fixed page size. The margin is in millimetres and applies equally to all four sides.
