Extract pages

Keep only some pages, or delete them from the document.

Keep only the pages you want, or do the opposite and remove the ones you do not. It is the same operation seen from both sides, and the switch flips it.

Useful for sending just the relevant chapter, dropping a blank cover, or removing pages with data you would rather not share.

How to use it

  1. Add the PDF.
  2. Type the pages, for example “1-3, 7”.
  3. Tick the box if you want to delete them rather than keep them.

Frequently asked questions

Can the deleted pages be recovered from the new file?
No. The output document is built by copying only the pages that are kept, so the rest are simply not there, hidden or otherwise.
Is the order I type respected?
Pages come out in ascending order, not in the order you type them. To reorder, use “Organise pages”.
Can I drop the last page without knowing how many there are?
Type a high enough number at the end of a range: it is clipped to the last page that exists.
