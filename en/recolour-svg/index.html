Recolour SVG

Change a whole set’s colours without opening them one by one.

A downloaded icon set never arrives in the colour you need. Opening them one by one to change a #000000 is exactly the kind of work a machine should be doing.

You can change every colour to a single one, one particular colour only, or everything to currentColor so the CSS decides. It looks at the attributes and also inside style=””, which is where a good half of the exporters leave them.

How to use it

  1. Drop in the whole icon set.
  2. Choose whether to change every colour, just one, or move them to currentColor.
  3. Pick the new colour and process.

Frequently asked questions

What is currentColor?
It tells the SVG to take the text colour of whatever contains it. The icon then changes colour on its own when the button it lives in changes, with no per-colour copies to keep.
Nothing changed — why?
The file probably has no colour written in it at all: an SVG with no fill is painted black by default. In that case we hand the original back with a note, rather than pretending something happened.
Does it touch colours inside a <style>?
No. That would mean understanding CSS properly, and leaving it to your editor’s find-and-replace is more honest than half-guessing.
