SVG to PDF

A one-page PDF at the drawing’s real size.

An SVG is a drawing, not a document: send it to a printer, attach it to an email or sign it, and what you will be asked for is a PDF. This makes a one-page one, with the page exactly the size of the drawing.

The conversion rasterises. Translating an SVG into a PDF’s own painting instructions — gradients, masks, clips, text with fonts — would mean writing a whole rendering engine inside the browser, and it would still be worse in the odd cases. So the drawing goes in as an image at the resolution you ask for, and the page comes out the right size in points.

How to use it

  1. Drop in the SVGs.
  2. Pick the resolution: 150 dpi for screens, 300 for print.
  3. Say whether the background should be transparent, and process.

Frequently asked questions

Will the PDF text be selectable?
No. The drawing goes in as an image, so any text inside the SVG stops being text. If you want a PDF with real text, export it from whatever you drew it in.
What resolution should I use?
150 dpi is fine for anything that will be looked at on a screen. For print, 300. Above 300 the file grows fast and almost nobody will see the difference.
Why is the page not A4?
Because a 200×80 px logo inside an A4 is mostly empty paper. The page comes from the size of the drawing; if you need it on A4, place it from your layout software.
