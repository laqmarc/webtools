Rotate PDF pages

Turn every page, or only the ones you name.

Fix pages that were scanned sideways or upside down. The rotation is added to whatever the page already has, so the result is what you see in the reader, not a sum you have to work out yourself.

You can turn the whole document or only a few pages, which is the usual case when the scanner has only turned the landscape sheets.

How to use it

  1. Add the PDF.
  2. Choose the angle and, if it is not all of them, type the pages.
  3. Process and download.

Frequently asked questions

How do I name only some pages?
With the same range notation: “1-3, 7, 10-12”. Leave the field empty and every page is turned.
Is the document recompressed?
No. Rotating a page changes one attribute in the PDF structure; the content is untouched and loses nothing.
Why did my reader already show the page the right way up?
Some readers rotate the view without saving it. This tool writes the rotation into the file, so it comes out right everywhere, including in print.
