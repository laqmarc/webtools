Split PDF

One page per file, blocks of N pages, or ranges you choose.

Split a PDF three ways: one page per file, blocks of a fixed number of pages, or the specific ranges you name.

The result is one file per piece, and when there is more than one they can be downloaded together in a ZIP with the names already numbered.

How to use it

  1. Add the PDF.
  2. Choose how to split it and, where relevant, type the ranges.
  3. Process and download the pieces.

Frequently asked questions

How are ranges written?
Comma separated, with a hyphen for intervals: “1-3, 7, 10-12” produces three files. Each comma-separated group becomes one output document.
Can ranges overlap?
Yes. Nothing stops you asking for “1-5, 3-8”; page 3 will appear in both files.
What if I ask for a page that does not exist?
Ranges are clipped to the last page of the document. If it has 10 and you ask for “8-50”, you get 8 to 10.
