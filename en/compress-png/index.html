Compress PNG

Shrink PNG screenshots and graphics, out as WebP with transparency.

PNG compresses losslessly, which means there is a floor it cannot go below: if the image has gradients or photographic noise, the file will be large and there is not much to do about it without changing format.

So this page is set up to produce a WebP. It keeps transparency just as PNG does, and for a typical screenshot the result is usually ten to thirty times lighter. If you need the output to stay PNG, switch the format to “Keep the original”: the gain will be far more modest.

How to use it

  1. Drop in the images you want to slim down.
  2. Choose whether to fix the quality or a maximum size in kilobytes.
  3. Check the percentage-saved column and download whatever convinces you.

Frequently asked questions

Why does my PNG barely shrink when I choose “Keep the original”?
Because the PNG was already compressed and this tool re-encodes it with the same lossless algorithm. Re-encoding a lossless format does not invent space: what really cuts the weight is moving to WebP or reducing the pixel dimensions.
Is lossless WebP as good as PNG?
It is identical pixel for pixel and, on average, 26 % smaller. The difference is support: every browser opens it, but some older desktop software still does not.
How can I cut the weight a lot without changing format?
By reducing the pixel dimensions. A 3000 px-wide screenshot that will be shown at 800 px has nine times more pixels than it needs.
