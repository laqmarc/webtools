JSON a YAML

Conversió directa mantenint l’ordre de les claus.

Passa un JSON a YAML mantenint l’ordre de les claus. És el que necessites quan has de posar una configuració que tens en JSON dins d’un docker-compose, un manifest de Kubernetes o un flux de treball de CI.

El resultat evita les referències i les àncores, de manera que és llegible i es pot enganxar tal qual encara que hi hagi estructures repetides.

Com es fa servir

  1. Enganxa el JSON.
  2. Ajusta la indentació si el teu projecte n’usa una altra.
  3. Copia el YAML.

Preguntes freqüents

Quina indentació he de triar?
Dos espais és la convenció majoritària i la que fan servir Docker Compose i Kubernetes. El YAML no admet tabuladors en cap cas.
Per què algunes cadenes surten entre cometes i altres no?
El YAML només les necessita quan el valor es podria confondre amb un altre tipus: «true», «null», «1.0» o una cadena que comenci amb un caràcter especial. Amb l’opció automàtica només se’n posen on calen.
Es conserva l’ordre de les claus?
Sí, surt el mateix ordre que tenia el JSON d’entrada.

Eines relacionades

JSON a CSVArray d’objectes a taula, aplanant els objectes imbricats. CSV a JSONDetecta el separador, respecta les cometes i tipa els valors. YAML a JSONAccepta diversos documents en un mateix fitxer. Formatar i validar JSONIndenta, minifica o ordena claus, i assenyala l’error amb línia i columna. Descodificar JWTCapçalera, càrrega útil i caducitat. La signatura no es verifica.

Res no puja a cap servidor. Tot el processament passa dins d’aquesta pestanya.
