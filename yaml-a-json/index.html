YAML a JSON

Accepta diversos documents en un mateix fitxer.

Converteix YAML a JSON per llegir-lo des de codi, validar-lo contra un esquema o simplement veure’n l’estructura sense dependre de la indentació.

Accepta fitxers amb diversos documents separats per «---»: en aquest cas el resultat és una llista amb un element per document.

Com es fa servir

  1. Enganxa el YAML o obre el fitxer.
  2. Tria la indentació de sortida.
  3. Copia o baixa el JSON.

Preguntes freqüents

Per què em diu que el YAML no és vàlid?
Gairebé sempre és la indentació: un tabulador enmig dels espais, o un nivell que no quadra. El missatge d’error indica la línia on el lector s’ha perdut.
Es perd informació en convertir?
Sí, la que el JSON no sap representar: comentaris, àncores i referències, i la distinció entre estils de cadena. Els valors hi són tots.
Què passa amb les dates?
El YAML les reconeix com a tipus propi; en passar a JSON es converteixen en cadenes de text en format ISO.
