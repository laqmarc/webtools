SVG a CSS

El dibuix dins d’un data URI, sense cap petició de més.

Una icona petita dins del full d’estil s’estalvia una petició sencera, i sobretot s’estalvia el moment en què la pàgina ja es veu però les icones encara no hi són. Això et torna l’SVG ja embolicat en la regla que has d’enganxar.

La codificació és amb percentatges, no amb base64. Un SVG és text: passar-lo a base64 l’engreixa un terç llarg a canvi de res. Només s’escapen els caractèrs que trencarien un url(), així que el resultat queda curt i encara es pot llegir.

Com es fa servir

  1. Afegeix-hi les icones.
  2. Tria si vols una regla, una variable CSS, una etiqueta <img> o només el data URI.
  3. Processa i enganxa el resultat al teu full d’estil.

Preguntes freqüents

Quan val la pena i quan no?
Per sota d’uns 3 kB gairebé sempre sí. Per sobre, el data URI viatja dins del CSS a cada càrrega i ja no es pot cachejar per separat: un fitxer a part surt més a compte.
Puc canviar-ne el color des del CSS?
Només el que sigui fons o màscara. Un data URI dins de background-image és una imatge i currentColor no hi arriba. Si el vols pintar amb CSS, fes servir un sprite amb <use>, o mask-image.
Per què les cometes són simples a dins?
Perquè la regla les fa servir dobles per fora. Canviar les de dins és la manera més curta de no haver d’escapar res més.
