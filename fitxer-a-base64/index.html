Fitxer a Base64

Genera un data URI llest per enganxar a CSS o HTML.

Converteix un fitxer en un data URI llest per enganxar dins d’un full d’estil, un HTML o un JSON de configuració. Serveix per incrustar una icona petita i estalviar-se una petició de xarxa.

Té sentit amb fitxers petits. A partir d’uns pocs kilobytes, incrustar surt a compte perdre: el recurs deixa de poder-se cachejar per separat i el full d’estil engreixa per a tothom.

Com es fa servir

  1. Deixa-hi el fitxer.
  2. Tria si vols el data URI complet o només el Base64.
  3. Processa i baixa el .txt.

Preguntes freqüents

Fins a quina mida val la pena incrustar?
Com a regla pràctica, per sota d’uns 4 kB. Per sobre, el creixement del 33 % i la pèrdua de caché acostumen a fer més mal que bé.
Puc incrustar un SVG?
Sí, però per a SVG sol anar millor codificar-lo amb percentatges en comptes de Base64: ocupa menys i continua sent llegible dins del CSS.
El tipus MIME surt bé?
S’agafa del que el sistema operatiu indica per al fitxer. Si el navegador no en sap el tipus, es posa application/octet-stream i el pots corregir a mà.

Eines relacionades
