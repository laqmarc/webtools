Minificar JavaScript

Terser en el navegador, con acortado de nombres opcional.

Minifica JavaScript con Terser, el mismo minificador que hay detrás de la mayoría de herramientas de compilación. Quita comentarios y espacios, acorta los nombres de las variables locales y simplifica el código muerto.

Funciona con sintaxis moderna, incluidos los módulos ES, el encadenamiento opcional y los campos privados de clase.

Cómo se usa

  1. Pega el código.
  2. Marca si es un módulo ES y elige el objetivo.
  3. Copia o descarga el .min.js.

Preguntas frecuentes

¿Por qué tengo que decir si es un módulo ES?
Porque los módulos van siempre en modo estricto y tienen ámbito propio. Si lo indicas, Terser puede acortar nombres que en un script clásico serían globales y no se podrían tocar.
¿Acortar los nombres me romperá algo?
Los nombres locales son seguros. Lo que sí rompe es el código que accede a ellos por cadena, como un framework que inyecta dependencias por el nombre del parámetro.
Me da un error de sintaxis que el navegador no me daba.
Terser analiza el archivo entero antes de nada. A menudo es sintaxis más nueva que el objetivo elegido: sube el objetivo a ES2020 y vuelve a probarlo.
