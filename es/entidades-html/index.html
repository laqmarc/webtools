Entidades HTML

Escapa el texto para meterlo dentro de HTML, o deshazlo.

Convierte «<», «>», «&» y las comillas en sus entidades, que es lo que hay que hacer para enseñar código dentro de una página sin que el navegador se lo trague como marcado.

En sentido inverso, la decodificación la hace el propio analizador del navegador, de modo que entiende todas las entidades con nombre que existen, no una lista corta.

Cómo se usa

  1. Elige la dirección.
  2. Pega el texto o el código.
  3. Copia el resultado.

Preguntas frecuentes

¿Qué caracteres se escapan por defecto?
Los cinco que tienen significado dentro del marcado —&, <, >, " y '— más el espacio duro. Con la casilla marcada, también todo lo que pase del código 127.
¿Hay que escapar los acentos?
No, si la página declara UTF-8, que debería ser siempre. La opción está para sistemas antiguos y para correos en HTML, que todavía sufren con la codificación.
¿Basta para evitar inyección de código?
Escapar para contenido HTML es una pieza, pero dentro de un atributo, de un <script> o de una URL las reglas son distintas. No te fíes de esta herramienta como medida de seguridad.
