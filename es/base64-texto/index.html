Base64 (texto)

Codifica y decodifica texto UTF-8, con variante segura para URL.

Codifica y decodifica texto en Base64, con soporte completo para UTF-8: los acentos, la eñe y los emoji pasan y vuelven intactos.

La variante segura para URL sustituye los caracteres + y / por - y _, y quita el relleno final, que es lo que piden los JWT y muchos parámetros de consulta.

Cómo se usa

  1. Elige la dirección.
  2. Pega el texto o el Base64.
  3. Copia el resultado.

Preguntas frecuentes

¿Base64 es cifrar?
No, en absoluto. Es solo una manera de representar datos con caracteres seguros para transporte. Cualquiera lo puede deshacer en un segundo: no sirve para proteger nada.
¿Por qué mi Base64 no se decodifica?
Suele ser el relleno. Esta página añade sola los signos «=» que falten y acepta tanto la variante estándar como la segura para URL, así que si aun así falla es que el texto está cortado.
¿Cuánto crece el texto?
Un tercio aproximadamente: cada tres bytes se convierten en cuatro caracteres.
