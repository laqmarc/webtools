Formatear y validar JSON

Indenta, minifica u ordena claves, y señala el error con línea y columna.

Indenta, minifica u ordena las claves de un JSON, y cuando no es válido te indica la línea, la columna y qué esperaba.

El motor del navegador ya no dice dónde falla, así que cuando el JSON no pasa, la página lo recorre de nuevo con un analizador propio que sí lo puede decir: «sobra una coma antes de }», «se esperaba el nombre de una clave entre comillas dobles», y siempre con la posición exacta.

Cómo se usa

  1. Pega el JSON, tan desordenado como haga falta.
  2. Elige si lo quieres indentado, minificado o con las claves ordenadas.
  3. Copia el resultado.

Preguntas frecuentes

¿Para qué sirve ordenar las claves?
Para comparar dos JSON que tienen el mismo contenido en distinto orden. Una vez ordenados los dos, un diff de texto solo muestra las diferencias reales.
¿Se sube el archivo a alguna parte?
No. Todo pasa dentro de la pestaña, cosa que importa cuando el JSON que pegas contiene claves de API o datos de clientes.
¿Acepta JSON con comentarios o comas finales?
No, y te lo dirá con la posición exacta. Eso no es JSON estándar, aunque algunos archivos de configuración lo admitan.
