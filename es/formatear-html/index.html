Formatear HTML

Indenta y ordena marcado desordenado o minificado.

Indenta HTML minificado o mal ordenado para que se pueda leer. Va bien para entender el código que te ha escupido una herramienta, para revisar una plantilla o para ver qué hay dentro de un correo en HTML.

Respeta los elementos en línea y no parte el texto en medio de un párrafo, que es lo que hace que una indentación automática sea útil en vez de molesta.

Cómo se usa

  1. Pega el marcado.
  2. Ajusta la indentación.
  3. Copia o descarga el resultado.

Preguntas frecuentes

¿Cambia lo que se ve en la página?
Con HTML bien formado, no debería. Los espacios entre elementos en línea sí cuentan, así que revísalo si tienes una maquetación delicada con inline-block.
¿Sirve para JSX o para plantillas?
Solo a medias. Las llaves de JSX y las etiquetas tipo {{ }} o <?php ?> lo despistan, porque analiza HTML y nada más.
¿Y para minificarlo?
Esta herramienta va en el otro sentido. Para adelgazar la página, lo que más cuenta es el CSS y el JavaScript, que tienen sus propias herramientas aquí mismo.
