Sprite SVG

Todo un juego de iconos en un solo archivo, para usarlo con <use>.

Veinte iconos son veinte peticiones, y al navegador cada una le cuesta más de lo que pesa. Un sprite los pone todos en un solo archivo como <symbol>, y luego cada uno se usa con <use href="#icono-flecha">.

De paso, si dejas marcada la opción de currentColor, los colores de dentro desaparecen y el color lo decide el CSS que los muestre: el mismo icono sirve para un botón claro y para uno oscuro sin duplicarlo.

Cómo se usa

  1. Deja aquí todos los iconos a la vez.
  2. Ponle un prefijo si quieres que los identificadores no choquen con nada.
  3. Procesa: sale un solo sprite.svg.

Preguntas frecuentes

¿Cómo lo uso?
Pega el contenido al principio del <body> y luego llama a cada icono con <svg><use href="#su-id"></use></svg>. Si lo dejas como archivo aparte, la referencia tiene que ser sprite.svg#su-id.
¿De dónde salen los identificadores?
Del nombre de cada archivo, en minúsculas y con guiones, con el prefijo delante. Si dos archivos acaban con el mismo nombre, al segundo se le añade un número.
¿Por qué mis iconos salen negros?
Porque con currentColor marcado heredan el color del texto. Pónles un color en el CSS de quien los usa, o desmarca la opción para conservar los colores originales.
