Formatear y validar XML

Indenta el documento y avisa si el marcado no cierra bien.

Indenta un documento XML y, de paso, comprueba que esté bien formado: si hay una etiqueta sin cerrar o un carácter ilegal, te lo dice antes de tocar nada.

Sirve para canales RSS, mapas del sitio, archivos de configuración y cualquier respuesta de API que llegue en XML en una sola línea inabarcable.

Cómo se usa

  1. Pega el XML.
  2. Elige la indentación.
  3. Copia el resultado.

Preguntas frecuentes

¿Qué significa que no es válido?
Que no está bien formado: una etiqueta sin cerrar, un «&» suelto que debería ser «&amp;» o dos elementos raíz. El mensaje indica qué esperaba.
¿Valida contra un esquema?
No. Comprueba la estructura, no si cumple un XSD o un DTD, que es una comprobación mucho más exigente.
¿Se conservan los comentarios y las secciones CDATA?
Sí, están en el resultado. Lo que puede cambiar es la indentación de lo que hay dentro.
